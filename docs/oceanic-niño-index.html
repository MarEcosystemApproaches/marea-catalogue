Contact:

10.1 Introduction to Indicator

The Oceanic Niño Index (ONI) is one measure of the El Niño Southern Oscillation pattern in the Pacific. ONI measures the 3-month running-mean anomaly of sea surface temperature in the Central Pacific from 30-year baselines that are updated every 5 years (Glantz and Ramirez 2020).

High ONI anomaly values for prolonged periods indicate a strong likelihood that an El Niño event will occur.

library(plotly)
plotly_df <- data@data %>%
  mutate(date = lubridate::make_date(year, month, day = 1)) %>%
  mutate(color = ifelse(anomaly > 0,"#d63227","#3e5eb8"))

p <- plot_ly(plotly_df, x = ~date,y = ~anomaly) %>%
  add_bars(marker = list(color = ~color),
           hovertemplate = "Anomaly Value: %{y:.2f}°C <extra></extra>")  %>%
    layout(
    title = "Oceanic Niño Index for Niño 3.4 region",
    xaxis = list(title = "Date",
                 hoverformat = "%b %Y" ),
    yaxis = list(title = "3-month running mean anomaly (°C)",
                 fixedrange = T),
    hovermode = "x unified",
    margin = list(t = 80)
    
  ) %>%
  config(displayModeBar = FALSE)

10.3 Trends

As of the most recent data entry in 7/2025, the ONI value is 27.12, which is moderate among values in the timeseries. The ONI value is currently above the long-term mean, and has been since 3/2025. The ONI value has followed a(n) decreasing trend in recent years (Fig. 10.1).

10.4 Relevance to Research and Stock Assessments

ONI and related El Niño indicators have strong effects on fisheries and oceanic and atmopheric processes in the Pacific, but are not expected to be major drivers of change in Atlantic Canada.
