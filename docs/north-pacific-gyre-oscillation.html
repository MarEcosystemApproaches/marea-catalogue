9 North Pacific Gyre Oscillation

Data Type: Tabular Data

Spatial Scope: North Pacific Gyre

Duration 1950-2025

Source: Di Lorenzo et al., http://www.o3d.org/npgo/

Contact:

9.1 Introduction to Indicator

The North Pacific Gyre Oscillation Index is a fairly new oceanographic index, created to describe changes in salinity, nutrients, and chlorophyll in the North Pacific that were not well-captured by existing indices such as PDO. NPGO is calculated as the second Empirical Orthogonal Function mode of Sea Surface Temperature and Sea Surface Height anomalies in the Northeast Pacific region, closely tracking the second principal component of Sea Surface Temperature anomalies (Di Lorenzo et al. 2008).

A positive NPGO phase indicates the existence of two gyres in the North Pacific, rotating counter to each other, in contrast to the single gyre described by a positive PDO (Di Lorenzo et al. 2008).

9.2 View Data 

library(plotly)
plotly_df <- data@data %>%
  mutate(date = lubridate::make_date(year, month, day = 1),
         smooth_1yr = zoo::rollapply(anomaly_value, mean, width = 12, partial = TRUE),
         smooth_10yr = zoo::rollapply(anomaly_value, mean, width = 120, partial = TRUE),
         overall_mean = mean(anomaly_value))


p <- plot_ly(plotly_df, x = ~date) %>%
  add_lines(y = ~anomaly_value,
            name = "Monthly Anomaly",
            line = list(color = "lightgrey"),
            hovertemplate = "Anomaly Value: %{y:.2f} <extra></extra>"
  ) %>%
  add_lines(y = ~smooth_1yr,
            name = "1-yr Smooth",
            line = list(color = "blue", width = 2),
            hovertemplate = "1-yr Smooth: %{y:.2f} <extra></extra>"
  ) %>%
  add_lines(y = ~smooth_10yr,
            name = "10-yr Smooth",
            line = list(color = "red", width = 2),
            hovertemplate = "10-yr Smooth: %{y:.2f} <extra></extra>") %>%
  add_lines(y = ~overall_mean,
            name = "Overall Mean",
            line = list(color = "black", width = 2, dash = "dash"),
            hovertemplate = "Timeseries Mean: %{y:.2f} <extra></extra>") %>%
  layout(
    title = "North Pacific Gyre Oscillation Index",
    xaxis = list(title = "Date",
                 hoverformat = "%b %Y" ),
    yaxis = list(title = "NPGO Index (normalized anomaly)",
                 fixedrange = T),
    hovermode = "x unified",
    margin = list(t = 80)
    
  ) %>%
  config(displayModeBar = FALSE)

p

9.3 Trends

As of the most recent data entry in 9/2025, the NPGO value is -1.0961735, which is low among values in the timeseries. The NPGO is currently in a negative phase, and has been since 12/2016. The NPGO value has followed a decreasing trend in recent years.

9.4 Relevance to Research and Stock Assessments

In Canada, NPGO has shown positive relationships with salmon productivity in Pacific regions (Malick et al. 2017). In Atlantic Canada, NPGO is not expected to be a major driver of fisheries productivity or ecological patterns.
